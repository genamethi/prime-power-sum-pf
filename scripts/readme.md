## Subfolders explained

This directory gets cluttered and since the scripts tend to be separate, I
prefer to keep a separate folder for each. 

exp-gcd - (written in Lua) is about whether the exponent differences have common factors
mers-tab - (scripted in gap) generates tables for Mersenne factors
